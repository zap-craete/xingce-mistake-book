# 行测错题本

一个为公务员行测备考做的错题管理网页——这是我用 AI 做出来的第一个完整小工具。

## 它能干什么

- **五大模块记错题**：言语理解、数量关系、判断推理、资料分析、常识判断，逐题记录题目、选项、我的答案、正确答案和出处
- **错因画像**：每道题打错因标签（方法不对、概念混淆、审题失误等），自动统计哪个模块、哪种错因最集中
- **间隔复习**：按 1 / 3 / 7 / 14 天的节奏自动排复习队列，到期提醒重做；连续答对 3 次才算掌握
- **自测模式**：复习时先做题、后看答案解析，不偷看
- **考试倒计时**：首页挂着目标考试的倒计时

## 为什么做这个

以前错题都记在本子上，记完就忘、从不回头看。这个工具逼着我按记忆曲线回头重做，还把错因攒成数据——比如最近 6 道言语错题里 5 道是“方法不对”，弱点一眼就看出来了。

## 数据快照

`data/` 里是错题本当前数据的导出快照（2026-11-05）：

- `mistakes.json`：结构化数据
- `mistakes.md`：可直接阅读的版本
